# Cluster-Sampling-Simulator-RShiny
An interactive R Shiny application developed as part of Asynchronous Assignment–2 to simulate cluster sampling, visualize population structure, and analyze estimation accuracy, sampling bias, survey cost, and time efficiency in real time.

Overview

This repository contains an R Shiny application developed for Asynchronous Assignment–2.
The application demonstrates the working of cluster sampling and compares it with simple random sampling through simulation and visualization.

Users can generate synthetic populations, perform cluster-based sampling, and instantly observe the impact on population mean estimation, sampling bias, survey cost, and time efficiency.

Key Features

Dynamic Population Generation

Customizable number of clusters and units per cluster

Control over population mean and variability

Realistic intra-cluster similarity

Interactive Cluster Sampling

Selection of number of clusters to sample

Visual identification of sampled vs unsampled clusters

Real-Time Survey Metrics

True vs estimated population mean

Sampling bias calculation

Survey cost estimation

Survey time estimation

Advanced Visualization

Cluster-wise population plots

Highlighting of sampled units

Distribution analysis across clusters

Sample Size Planning

Estimation of required number of clusters for desired precision
